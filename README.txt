MY MONEY TRACKER — ANDROID PWA

What this is:
A phone-style Progressive Web App (PWA) for the personal money tracker.
It has:
- 100 SAR daily allowance
- Daily expense tracking
- Rent / Travel / Investment / Car Repair
- Monthly income
- Monthly totals
- Local browser storage
- Offline app shell after first load
- Home-screen installation

IMPORTANT:
A PWA must be served from HTTPS (or localhost). Opening index.html directly as a file will
not enable installation/service-worker features.

EASIEST DEPLOYMENT:
1. Upload this whole folder to any HTTPS static hosting service.
2. Open the HTTPS site in Chrome on Android.
3. Tap the Chrome menu (⋮).
4. Choose "Add to Home screen" or "Install app" (wording can vary).
5. Confirm.

The app stores transactions locally in the browser/device. Clearing browser site data can erase
the locally stored transactions, so keep a backup/export feature if the tracker becomes important.
